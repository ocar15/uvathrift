Team project completed during Fall 2025.

I contributed most significantly as the DevOps lead for this project, which entailed:

- Configuring and initializing the Django app.
- Setting up Heroku hosting and connecting our app.
- Implementing AWS S3 bucket storage for user image uploads and remotely hosting our static files.

Separately, I built the user profile system for the app. This meant building the profile dashboard, designing profile editting forms, and implementing the user profile photo upload and automatic thumbnail conversion system.

All of us on the team gathered requirements from local UVA students and met biweekly for sprint reports where we reviewed our individual progress and assigned tickets for the following sprint cycle.

NOTE: This project is no longer hosted, but you can find a demo video of my contributions at oscaringram.com
